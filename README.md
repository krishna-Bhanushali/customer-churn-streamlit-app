# 📊 Customer Churn Prediction App

An AI-powered machine learning web app that predicts whether a customer is likely to churn based on customer behavior and subscription details.

---

## 🚀 Live Demo

🔗 Try the App Here:  
(https://customer-churn-app-app.streamlit.app/)
---

## 📖 Overview

This project predicts whether a telecom customer is likely to churn using Machine Learning.

The model analyzes customer information such as:

- Tenure
- Monthly charges
- Contract type
- Internet service
- Payment method
- Dependents
- Gender

and predicts the probability of churn.

## 🤖 Machine Learning Model

**Model Used:** Logistic Regression

Why Logistic Regression?

- Fast and lightweight
- Works well for binary classification
- Good interpretability
- Suitable for churn prediction

## ⚙️ How to Run Locally

### Clone repository

```bash
git clone (https://github.com/krishna-Bhanushali/customer-churn-streamlit-app)
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run app

```bash
streamlit run app.py
```
